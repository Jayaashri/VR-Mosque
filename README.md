# VR Mosque – Interactive Virtual Reality Environment

## Overview

VR Mosque is an immersive virtual reality project developed using **Unity, C#, Blender, and XR Interaction Toolkit**. The project focuses on creating an interactive 3D mosque environment that allows users to explore architectural spaces and experience a realistic virtual setting.

The project combines 3D environment design, VR interaction development, and collaborative software development.

## Features

- **Immersive VR Environment:** A detailed 3D mosque environment designed for virtual exploration.
- **Interactive VR Components:** VR interactions developed using Unity and C#.
- **3D Environment Design:** Mosque architectural spaces, including the lobby and bathroom areas.
- **Custom 3D Assets:** Environment assets created and integrated using Blender.
- **VR Navigation:** User movement and exploration within the virtual environment.
- **Collaborative Development:** Integration of 3D assets and VR functionality into a unified Unity project.
